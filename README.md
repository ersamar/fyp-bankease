# BankEase

BankEase is a modern digital banking application developed and customized as a Final Year Project. The project provides a user-friendly banking interface with features for managing accounts, viewing financial information, and performing banking-related operations.

## Features

* Modern and responsive banking interface
* User authentication and account management
* Banking dashboard
* Account and transaction management
* Financial information display
* Responsive design for different screen sizes
* Updated dependencies and modernized implementation
* Additional customizations and improvements made for the Final Year Project

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* JavaScript
* Node.js

## Database

**No database is connected to the code currently pushed to this GitHub repository.**

The project can be cloned or downloaded and further configured to connect to your own database and backend services. You can modify the database configuration, API endpoints, authentication, and other required services according to your requirements.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ersamar/fyp-bankease.git
cd fyp-bankease
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open the application in your browser at:

```text
http://localhost:3000
```

## Database & Backend Setup

If you want to use BankEase with your own database, configure your preferred database and backend services, add the required environment variables, and update the relevant API/database configuration in the project.

Do **not** commit your `.env` file or API keys to GitHub.
