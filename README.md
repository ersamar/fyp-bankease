# BankEase

BankEase is a significantly enhanced and customized banking application developed as my Final Year Project.

## About the Project

This project was initially based on the open-source banking application by Adrian Hajdin. I used the original project as a starting point for learning and development, but the current version has been extensively modified and expanded.

Since the original project used older dependencies and technologies, I updated the project dependencies and made substantial changes to the codebase, UI, functionality, and overall structure. I also implemented additional features and customized the application to meet the requirements of my Final Year Project.

## Key Changes & Improvements

- Updated outdated project dependencies
- Modernized the existing codebase
- Added new functionality and features
- Redesigned and customized the user interface
- Improved application structure and components
- Added additional banking-related features
- Fixed and updated deprecated implementations
- Customized the application for my Final Year Project

## Original Project

The project was initially inspired by and based on the open-source work of Adrian Hajdin. The original project served as a foundation for this application, while the current version contains substantial modifications and additional development.

This application was developed as a Final Year Project to demonstrate modern web development, application architecture, API integration, and the development of a digital banking platform.
